# Tableau Public dashboard: build sheet

The three CSV files here are regenerated by `python src/run_all.py`. Tableau Desktop cannot be
scripted from this repository, so the dashboard is assembled by hand in **Tableau Public**
(free, runs on macOS and Windows) and published to a Tableau Public profile.

| File | Grain | Use it for |
|---|---|---|
| `workers.csv` | one row per worker (3,443) | distributions, filters, drill-down |
| `article9_items.csv` | one row per employer × reporting item (group included) | KPI tiles and the gap chart |
| `categories.csv` | one row per employer × category (28) | the Article 10 screen |

## Colours

Use the same validated palette as the report, so the dashboard reads as part of the series:

| Role | Hex |
|---|---|
| Series 1 (mean, highest band, men) | `#2a78d6` |
| Series 2 (median, lowest band, women) | `#eb6834` |
| Flag: women paid less | `#e34948` |
| Flag: men paid less | `#2a78d6` |
| Below threshold | `#f0efec` |
| Text | `#0b0b0b` primary, `#52514e` secondary |

## Sheets

1. **KPI tiles** (`article9_items.csv`): filter `code` to one employer through a parameter;
   show `a_mean_gap_hourly`, `c_median_gap_hourly`, `b_mean_gap_components`,
   `f_q4_share_women` as big numbers with the item label underneath.
2. **Gap by employer** (`article9_items.csv`): bars, `employer` on rows, `value` on columns,
   `item_key` in (`a_mean_gap_hourly`, `c_median_gap_hourly`) on colour, one axis, value
   labels at the bar end.
3. **Pay bands** (`workers.csv`): `quartile` on columns, `COUNT(worker_id)` on rows as a
   percentage of the band, `sex` on colour; filter by `entity`.
4. **Article 10 screen** (`categories.csv`): highlight table, `employer` on rows, `category`
   on columns, `gap_hourly` as text; colour by a calculated field
   `IF [status] = "Justify or remedy" THEN (IF [gap_hourly] > 0 THEN "Women paid less" ELSE "Men paid less") ELSE "Below 5%" END`.
   Tooltip: women, men, `gap_annual`, `remedy_cost`, and `small_cell`.
5. **Where the pay sits** (`workers.csv`): strip plot of `hourly_total` by `category`, coloured
   by `sex`, filtered by `entity`, so a flagged category can be opened and read.
