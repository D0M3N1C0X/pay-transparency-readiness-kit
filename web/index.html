How gender is written in the file

Check each code. Exports differ: in Spanish files M can mean mujer, in German files d means divers. Workers marked "not compared" still count for the employer's size.

3Work of equal value

Score each role from 1 to 5. Points = skills × 35 + effort × 15 + responsibility × 35 + working conditions × 15; the points set the category. Your scores are remembered on this computer.

Pay gap assessment

What each employer owes, and when

Article 9(2)-(4): the size of the employer sets how often it reports and from when. A gap of 5% or more in a category has to be justified or remedied within six months of the report (Article 10).
